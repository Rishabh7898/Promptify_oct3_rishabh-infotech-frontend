Course / Module 2 / Lesson 204

Polymorphism: Compile-Time vs Runtime Dynamic Method Dispatch

HD 1080p • 42 mins JVM Internals & vtable Demo

Lesson Summary

In this deep dive, we demystify how the JVM executes method calls at runtime. You will learn the difference between early binding (compile-time) and late binding (runtime dynamic dispatch).

Key Takeaways:

  • • Compile-time polymorphism is achieved via method overloading within the same class.
  • • Runtime polymorphism is implemented with method overriding using the virtual method table (vtable).
  • • Static methods, private methods, and final methods are NOT resolved dynamically (they are non-virtual).
PaymentServiceDemo.java 
// Polymorphism & Dynamic Dispatch Example
public interface PaymentGateway {
    void process(double amount);
}

public class UpiGateway implements PaymentGateway {
    @Override
    public void process(double amount) {
        System.out.println("Processing instant UPI payment: ₹" + amount);
    }
}

public class CardGateway implements PaymentGateway {
    @Override
    public void process(double amount) {
        System.out.println("Processing 3D-Secure Card payment: ₹" + amount);
    }
}

public class Main {
    public static void main(String[] args) {
        // Parent interface reference pointing to runtime instance
        PaymentGateway gateway = new UpiGateway();
        gateway.process(1500.0); // Dynamically dispatches to UpiGateway.process()
    }
}
